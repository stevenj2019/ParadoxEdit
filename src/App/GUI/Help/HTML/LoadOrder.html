Workspaces & Load Order Resolver

Workspaces

Workspaces, much like their IDE Counterparts, allows you to open multiple sources at once. You can load vanilla files into the editor, as well as mods using the .mod files (the one with the file_path, where steam, installs other mods)

you can also save these workspaces as a file, to open them later with all within the Workspace menu

Load Order Resolver

Workspaces are the intentional solution to load order resolution, this applies overrides for you, closly mimicking Paradoxes own load order resolution (if you notice any consistencies, go to report an issue tab in this section).
this includes:

  1. DLC Overrides
  2. replace_path Overrides
  3. direct override (same file, in same place) Overrides
This will actively removes files that paradox would not load, giving you a visual represenation of what is loaded, so you can find hidden bugs!
