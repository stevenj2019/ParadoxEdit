Paradox Edit

ParadoxEdit is a context-aware editor for Paradox script files, designed to make paradox modding easier by understanding files, instead of managing raw text files

This is not intended to replace coding altogether, but to manage bulk-edits, and as the project matures. providing simpler actions, as well as resolve difficult questions, e.g. LoadOrder Resolution

This Section, and its pages, include some less clear information about the editor, which isnt intuitive, you can navigate these pages to the left.

Thank you for trying the tool!
