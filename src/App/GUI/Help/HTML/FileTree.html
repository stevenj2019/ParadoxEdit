File Tree

File Tree is a directory tree reperesenation of each of the "sources" loaded into your workspace,
this result is post-load resolution (e.g. dont see the file? it should not be loaded) you can double click on any of these files, and it will open to your right,

Advanced Features

they are still, sparse, but included is a Contextmenu (right click to access it)
this will provide relevant bulk actions (such as clearing comments/whitespace, bulk GFX installs, etc.)
when changes are made, they will be marked with a dot to indicate the change,
red = marked for deletion
yellow = modified
green = added
NOTE: none of these changes are live, and will only take effect, once they are saved. (if you have safe_mode enabled, the app will generate .bak copies, you can use to restore mistakes)
