File Tree View

clicking on any code files (*.txt, *.gui, *.gfx) will open the File view This is a tree view of your paradox code

InLineEdit utility

double clicking on any text, will create an edit session, which you can freely type a new value, clicking away, will cancel reverting it back to its previous value, pressing enter will commit the value, and mark the change (yellow for modified)

Context Actions

as with File Tree, these are loaded with some contextual actions, adding nodes/blocks(marks green), marking for deletion (marks red)
these work identically to the file tree, and will not take affect until it is saved.

Context Painting/Editors

some files (just events as of writing) will provide painted warning, e.g. loc key doesnt exist, icons doesnt exist
with some tools relating (icon viewer/localisation modification)

Keyboard Shortcuts

Ctrl+C this will copy the selected row. (if you just want the value/key, this is available as a context action)
